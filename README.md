# BrightBytes Solutions

A responsive company website for BrightBytes Solutions, founded by Luvala Kelvin.
Built with Next.js, React and TypeScript.

## Run locally

Install Node.js 20 or newer, then run:

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Pages

- `/` — Company introduction, featured services and delivery process.
- `/services` — Digital marketing, social media and Google Business services; automation; Zoho and Odoo; web and software development; IT support and training.
- `/about` — BrightBytes approach and founder profile.
- `/contact` — Email, phone and location.

## Production check

```bash
npm run lint
npm run build
```

## Customize

- `data/portfolio.ts` — Service descriptions and delivery process.
- `components/SiteChrome.tsx` — Shared navigation and footer.
- `app/globals.css` — Colors, layout and responsive styles.

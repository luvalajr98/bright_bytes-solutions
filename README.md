# BrightBytes Solutions

**Smart systems. Real growth.**

BrightBytes Solutions is a responsive company website for a Nairobi-based technology and digital solutions business founded by Luvala Kelvin. It introduces the company, presents its services and working approach, and gives prospective clients a clear way to get in touch.

## What the website showcases

- **Home** — Company introduction, featured services, delivery process and calls to action.
- **Services** — Digital marketing, social media management, Google Business Profile services, business automation, Zoho and Odoo solutions, web and software development, IT support, and technology training.
- **About** — The founder, company principles and a collaborative approach to delivering practical solutions.
- **Contact** — Direct email and WhatsApp links, plus the company’s Nairobi, Kenya location.
- **Responsive experience** — Shared navigation and footer, consistent visual styling, and layouts designed for different screen sizes.

## How BrightBytes works

Projects follow a clear, collaborative process:

1. **Discover** business goals and challenges.
2. **Plan** a practical strategy together.
3. **Develop** and integrate a solution around the business.
4. **Test** quality, security and performance.
5. **Deploy** carefully and prepare the team.
6. **Support** and improve the solution over time.

## Technology

- [Next.js](https://nextjs.org/) 15 with the App Router
- [React](https://react.dev/) 19
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/) 4 tooling, with site styles in `app/globals.css`
- [Lucide](https://lucide.dev/) icons

## Run locally

**Requirements:** Node.js 20 or newer and npm.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the local development server. |
| `npm run lint` | Run ESLint on the application, components and data files. |
| `npm run build` | Create a production build. |
| `npm run start` | Serve the production build locally. |
